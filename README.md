# Voxel Diving

A fast voxel skydiving arcade game that runs in your browser. A little alien falls toward walls with a letter-shaped hole: match the letter and the lane before each wall arrives.

**Controls:** Z X C V pick the letter pose, Left and Right arrows change lane, P pauses, M turns sound on or off. Keyboard only for now.

Started in the Jabali AI voxel game jam (September 2026), then remastered.
